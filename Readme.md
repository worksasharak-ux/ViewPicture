"
Приложение создано для создания постов с изображениями, которые добавил пользователь.
Для создания поста нужно быть зарегистрированным пользователем.
Комментарии к посту могут оставлять и не зарегистрированные пользователи."

* **Backend:** Python 3.14+, Django 5.0
* **Database:** SQLite
* **Дополнительно:** Django REST Framework
